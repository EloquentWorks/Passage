# 🔐 Security

Passage does not authorize the underlying action. A completed step means the package recorded or detected completion; applications must still use policies and gates.

- Validate all metadata before storing it.
- Escape metadata rendered in Blade.
- Restrict audit-log access.
- Do not expose private passage state through public APIs without authorization.
- Treat administrative overrides as privileged actions.
- Use class-string conditions in cached configuration.
- Ensure reminder destinations cannot leak private URLs.
- Select retention periods consistent with privacy obligations.
